# Exercício B / Exercise B

## Português

Faça um programa que leia 8 números inteiros digitados pelo usuário e, sem usar `max()`, `min()` ou `sorted()`, informe:
- O maior valor.
- O menor valor.
- A diferença entre o maior e o menor (amplitude).
- Em que posição (índice, começando em 1) o maior valor foi digitado.

## English

Write a program that reads 8 integers entered by the user and, without using `max()`, `min()`, or `sorted()`, reports:
- The largest value.
- The smallest value.
- The difference between the largest and smallest (range).
- At which position (index, starting at 1) the largest value was entered.
