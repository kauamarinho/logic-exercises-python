# Exercício A / Exercise A

## Português

Faça um programa que calcule a média salarial de uma empresa. Peça a quantidade de funcionários (validando que seja um número positivo) e, para cada funcionário, peça o salário (validando que seja maior que zero e menor ou igual a R$ 50.000,00).

No final, mostre:
- A média salarial da empresa.
- Quantos funcionários ganham acima da média.

## English

Write a program that calculates a company's average salary. Ask for the number of employees (validating that it is a positive number) and, for each employee, ask for the salary (validating that it is greater than zero and less than or equal to $50,000.00).

At the end, display:
- The company's average salary.
- How many employees earn above the average.
